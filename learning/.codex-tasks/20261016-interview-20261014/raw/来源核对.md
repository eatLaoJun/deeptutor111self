# 来源核对摘要

核对日期：2026-10-16。仅查询通用技术问题，未将个人转写上传到外部服务。

- Python threading / asyncio / free-threading：确认传统 CPython GIL 与 I/O 并发、CPU 并行的区别，以及可选 free-threaded build 的版本边界。
- Pydantic strict mode / errors：确认严格校验与默认类型转换不同，校验错误可定位到字段路径并返回错误类型。
- JSON Schema object：确认 properties 不自动等于 required，额外字段需要独立配置。
- 阿里云结构化输出：确认 JSON Object 与 JSON Schema 模式有别，具体支持模型和关键字受接口约束。
- json_repair 作者仓库：确认语法修复基于解析和启发式，不是业务事实正确性的证明。
- LangGraph persistence / interrupts：确认 checkpointer、thread_id、中断与恢复能力；节点恢复可能重跑中断前代码。
- pyBKT 原始论文与作者仓库：确认 BKT 的 HMM 表述、四参数与 EM 参数估计；不据此指认用户实际训练库。
- Sentence Transformers 官方资料、SBERT 原论文与 Qwen 官方模型卡：确认独立编码和联合相关性评分的区别，不把所有 Reranker 都说成 BERT 双向编码器。
- RRF 原论文：确认基于名次融合，不直接对异量纲原始分数相加。
- W3C XSD：确认 XML 结构与类型约束，领域动态事实仍需要应用校验。
- vLLM 官方硬件文档：确认不同硬件后端有独立兼容性边界，不写死某个当前版本作为项目经验。

所有最终引用和本地项目资料索引收录于交付目录 `05_资料来源与核对说明.md`。
