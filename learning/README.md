# 学习计划与笔记

这个目录是 **个人学习过程** 的存放处，不是项目交付物的一部分。

- `plans/`：学习计划与排程（骨架速通、逐日啃点队列）。
- `notes/`：学习过程的草稿、口述费曼记录、临时 Q&A。

当前使用中的计划：

- `plans/resume-interview-7day-plan.md`：围绕简历“极光智能学习机”项目的一周面试准备计划；后续复习和模拟面试优先读取此文件及对应的 `notes/day*.md`。

与项目正式知识库的区别：

| 这里（`learning/`） | 项目知识库（`DeepTutor项目学习手册.md`） |
| --- | --- |
| **过程**：计划、排程、草稿 | **产物**：已验证的长期结论 |
| 可消耗、会过期、会勾选推进 | 稳定、要引证据、合并进现有章节 |
| 给“学习中的我”看 | 给“任何想理解这个项目的人”看 |

确认可靠的小结论后，请摘出来合并进手册对应章节；这里只留过程痕迹，不要把长期结论堆在这里。
