# 学习计划与笔记

这个目录是 **个人学习过程** 的存放处，不是项目交付物的一部分。

- `plans/`：学习计划与排程（骨架速通、逐日啃点队列）。
- `notes/`：学习过程的草稿、口述费曼记录、临时 Q&A。
- `interview-scripts/`：已经整理好的多时长面试口述稿，用于日常录音和模拟面试。
- `demos/`：用于验证某个架构想法的可运行学习原型，不代表已接入生产链路。

当前使用中的计划：

- `plans/resume-interview-7day-plan.md`：围绕简历“极光智能学习机”项目的一周面试准备计划；后续复习和模拟面试优先读取此文件及对应的 `notes/day*.md`。
- `interview-scripts/DeepTutor多时长项目介绍.md`：15 秒、30 秒、60 秒、90 秒和 3 分钟项目介绍，以及第一条职责的专项版本。
- `interview-scripts/DeepTutor三层记忆多时长介绍.md`：Memory 专项 3、5 分钟口述稿及面试追问，
  重点讲 L1 原始事件、L2 场景记忆、L3 增量归并和关系库实现。
- `interview-scripts/鼎校伴学-Agent-Runtime-3分钟与5分钟.md`：对应简历第一条职责，包含
  Agent Runtime 专项 3、5 分钟口述稿、速记主线和表达边界。
- `interview-scripts/鼎校伴学-Agent-Runtime-面试追问.md`：主 Agent/Subagent、Skill、DAG、
  Plan 模式、指标口径与项目亮点；区分当前项目介绍与扩展设计。
- `interview-scripts/鼎校伴学-第三条-K12教材RAG面试讲解.md`：对应简历第三条职责，覆盖
  教材入库、Qdrant + BM25 双路召回、RRF 融合、Qwen-Rerank 重排、指标及高频追问；默认
  使用 60 秒版本，把面试重点留给 Agent Runtime 和三层记忆。
- `interview-scripts/AI全栈工程师-3分钟自我介绍.md`：面向 AI 全栈岗位的完整自我介绍，
  明确鼎校伴学是鼎校甄选中的 AI 入口，以及本人参与的 3 类重点学习服务。

与项目正式知识库的区别：

| 这里（`learning/`） | 项目知识库（`DeepTutor项目学习手册.md`） |
| --- | --- |
| **过程**：计划、排程、草稿 | **产物**：已验证的长期结论 |
| 可消耗、会过期、会勾选推进 | 稳定、要引证据、合并进现有章节 |
| 给“学习中的我”看 | 给“任何想理解这个项目的人”看 |

确认可靠的小结论后，请摘出来合并进手册对应章节；这里只留过程痕迹，不要把长期结论堆在这里。
