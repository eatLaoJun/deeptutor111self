## 鼎校伴学定位

面试中可以用下面这句话定义项目：

> 鼎校伴学是面向鼎校甄选用户建设的 AI 伴学项目，以自然语言对话作为统一入口，并通过
> 受控 Action 连接约 7 类确定性学习服务；我除参与 Agent Runtime 等通用能力建设外，
> 还参与了词汇量检测、英语三合一和试卷学情分析的设计与开发。

它解决的核心问题不是“再做一个聊天机器人”，而是：

1. 用户可以用自然语言表达学习需求，不必先在产品中寻找具体功能。
2. 普通知识问题由 Agent 在当前对话中直接回答。
3. 测评和分析等确定性任务通过受控 Action 进入已有业务服务。
4. 任务结果可以回到会话和用户画像，支撑后续连续对话与个性化服务。

## 表达边界

1. 先说明鼎校伴学是 AI 伴学项目，再介绍它以对话为入口连接学习服务；不要将其弱化为一个功能点。
2. 不说“我负责了全部 7 类服务”，而说“入口连接约 7 类服务，我重点参与其中 3 类”。
3. 不把“跳转”描述成模型自由生成 URL，而说“模型调用受控 Action，由后端映射业务服务”。
4. 不把所有业务强行 Agent 化。开放式问答由 Agent 处理，确定性测评和分析仍由业务服务执行。
5. 开场保留“约 7 类服务”和“891 本教材”两个规模信息，其他评测指标留给项目追问。
