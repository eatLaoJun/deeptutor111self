# 鼎校伴学｜AI 应用开发

**项目时间：** 2025.09—至今

**技术栈：** Python、AsyncIO、FastAPI、LLM Function Calling、Qdrant、BM25、Rerank、MySQL、Redis、OCR / 多模态模型

**项目介绍：** 面向 K12 教育产品建设统一 Agent 交互入口，整合教材检索、题库和学习记忆，提供多轮问答及错题、知识点讲解能力，并以结构化 Action 连接测评、试卷学情分析等业务；在既有能力基础上设计教学 Workflow，将单次讲解延伸为诊断、练习与理解验证相衔接的学习任务。

## 1. Agent Runtime 与错题、知识点辅导

- **执行与工具治理：** 参与 Agent Runtime 建设，通过 Agent Loop 串联模型决策、工具执行与结果回填，以 Tool Registry / ToolResult 统一工具注册、参数注入、异步执行和失败隔离，支撑多轮问答与动态教材检索。
- **收敛与可观测性：** 结合轮次限制、上下文裁剪及 Forced Finish 明确执行结束边界，通过统一 Trace 关联模型和工具调用，支持异常定位与执行回溯。
- **教学 Workflow：** 围绕教研定义的错题与知识点讲解流程，设计“错因诊断—针对性讲解—练习—学生复述与理解验证”Workflow；外层管理阶段、等待及有限补救，内层按需调用 Agent Loop，形成以作答和解释证据校验学习结果的辅导方案。

## 2. 分层记忆与上下文治理

- **学习记忆与画像：** 设计分层记忆方案，保留原始学习证据，提炼任务级场景事实并增量维护用户画像；仅针对实际涉及的知识点与偏好更新，结合新证据和历史来源处理冲突，为跨会话辅导提供可追溯参考。
- **上下文优化：** 基于 UnifiedContext 按任务装配近期对话、相关记忆、教材证据及工具结果，通过摘要压缩与优先级裁剪，使 **10 轮以上长会话的单次模型调用平均输入 Token 降低 37%**；设计按用户和知识点查询历史的机制，将学习经历与任务执行状态分离。

## 3. 教材 RAG 与知识覆盖优化

- **知识点结构化：** 参与约 **6.6 万页教材**的清洗与结构化，依托教研章节知识点树组织切块，协作形成约 **9.2 万个 Chunk**；跨块保留知识点关联及教材版本、章节、页码等元数据，支持范围过滤与来源追溯。
- **混合检索：** 参与 **Dense Embedding + BM25** 双路检索方案设计，经 **RRF 融合去重、Rerank 语义重排**选取 Top 10 证据；在 600 条标注问题上，完整检索链路的 **Recall@5 由 73% 提升至 94%**。
- **知识覆盖优化：** 分析检索失败案例，区分“已有证据未召回”与“教材缺少充分讲解”，反馈教研补充细粒度知识点材料，配合知识库更新与回归验证，推动检索问题定位和内容补齐。

## 4. Action 学习服务接入

根据用户诉求返回结构化 Action，连接英语三合一、单词测评和试卷学情分析等业务入口，由前端展示并引导用户进入对应服务；将任务结果关联原会话回写，打通需求识别、业务引导与结果回流。

## 5. OCR 与多模态解析

接入 OCR 与多模态解析能力，结合 OpenCV 预处理、结构校验和字段归一化，输出题目、版面及坐标信息；在文档处理链路中将表格转为 Markdown、图片存入 OSS 并关联文本片段，支撑教材图文追溯、试卷学情分析与错题归档。
