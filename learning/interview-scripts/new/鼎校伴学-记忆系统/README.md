# 鼎校伴学：记忆系统专题

对应简历第 3 条“分层记忆”。按已实现项目口吻口述；数字类配置为示例值，面试前替换为真实配置。

层级：原始数据（不计入三层）→ L1 信息提取与标签 → L2 任务/轮次记忆 → L3 用户画像。

## 阅读顺序

1. [L3 用户画像：怎么从 L2 得出对用户的认识](L3用户画像-怎么做.md)：L2/L3 多对多、粗心与情感画像的例子、每次对话如何加载 L3。
2. [证据驱动分层记忆设计方案](鼎校伴学-证据驱动分层记忆设计方案.md)：完整方案，含写路径、读路径、L2 向量检索、冲突处理、一致性；
   第 13 节借鉴 Hello-Agents（工作记忆、重要性、整合、遗忘，不用图数据库）；第 14 节为什么不做独立记忆 Agent。
3. [三层记忆与知识点学习 Workflow](三层记忆与知识点学习Workflow-面试讲解.md)：记忆与学习 Workflow 的衔接、画像表结构。

## 背诵主线

- L1 理清每次输入，L2 记住一次经历，L3 形成对用户的认识。
- 多次独立经历才能形成认识；画像有支持也有反例，可修正。
- L3 按场景常驻加载，L2 按需检索；Workflow 管进度，Memory 管经历。
- 记忆是服务 + 工具，不是自主 Agent；模型提候选，程序决定写入。
