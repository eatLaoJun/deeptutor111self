## 可直接替换版

### 鼎校伴学｜算法工程师｜2025.09—至今

**技术栈：** Python、AsyncIO、FastAPI、Agent Runtime、LLM Function Calling、RAG、Memory、OCR/多模态

**项目简介：** 面向 K12 场景建设 Agent-Native 智能伴学平台，以统一 Agent Runtime 串联多轮推理、工具调度、上下文及长期记忆，并整合教材 RAG、知识点图谱、题库和 OCR/多模态解析能力。平台覆盖 **891 本教材**，支撑英语三合一、单词测评、试卷学情分析等 **约 7 类学习服务**，形成从对话理解、知识检索到学习任务执行和结果回流的业务闭环。

#### 1. Agent Runtime 核心建设

- **执行闭环：** 基于 Agent Loop 打通“模型推理—工具调用—结果回填—继续决策”链路，统一支撑问答、解题与学习服务编排。
- **工具调度：** 通过 Tool Registry 和 `ToolResult` 实现参数注入、异步执行、调用去重与失败隔离，单工具异常可回填模型继续处理。
- **收敛与观测：** 结合轮次限制、重复调用检测、上下文裁剪及 Forced Finish 保证任务明确结束，并通过统一 Trace 定位模型与工具异常。

#### 2. 分层上下文与长期记忆

- **分层记忆：** 建设 L1 原始证据、L2 场景记忆和 L3 长期画像，通过 LLM 提取、去重及增量归并持续沉淀用户学习状态。
- **上下文治理：** 动态装配近期对话、历史摘要和长期记忆，使 10 轮以上长会话的单次模型调用平均上下文 Token **降低 37%**，减少上下文超限风险。
- **个性化效果：** 在 200 条跨会话测试中，用户偏好与学习状态的关键信息召回率由 **71% 提升至 88%**，支撑连续追问和个性化讲解。

#### 3. K12 教材 RAG

- **教材入库：** 完成 **891 本教材、约 18.2 万页内容**的解析与结构化，页面解析成功率 **98.4%**，按章节小节生成约 **32 万个 Chunk**并补充层级元数据。
- **混合检索：** 采用 Dense Embedding + BM25 召回及 RRF 融合，在 600 条标注问题上将 Recall@5 由 **73% 提升至 86%**。
- **生成质量：** 通过元数据过滤和 Top 5 证据收敛，将 RAGAS Faithfulness 由 **0.82 提升至 0.90**，增强回答一致性和来源可追溯性。

#### 4. 学习服务落地与业务闭环

- **服务覆盖：** 将 Runtime、长期记忆、教材知识库和题库能力复用至问答、测评、讲解、学情分析等 **约 7 类学习服务**。
- **重点落地：** 重点负责英语三合一、单词测评和试卷学情分析，通过意图识别、知识检索及结构化 Action 连接对话与学习任务。
- **业务闭环：** 上线首月覆盖约 **8400 个入口展示会话**，点击率提升 **22%**、任务完成率达到 **71%**；结果回写 Session 并更新用户画像。

#### 5. 教育 OCR 与多模态文档理解

- **OCR 服务化：** 集成 PaddleOCR-VL 与 MinerU，完成试卷、错题本和作业图片的版面与题目结构化，并通过 Redis/OSS 管理任务和结果。
- **多模态结构化：** 基于 Qwen-VL 和 JSON Schema 处理手写/印刷混合、多图及复杂版面，通过重试、清洗和字段归一化提升稳定性。
- **图像增强与落地：** 使用 OpenCV 完成光照增强、清晰度检测、倾斜矫正和坐标映射，支撑试卷学情分析、错题归档与作业批改。

## 写法说明

本版采用隐式 STAR，而不是在每个节点中机械地写四段：

- 项目简介说明业务背景、平台目标和覆盖规模，对应 Situation 与 Task。
- 五个重点节点直接写本人完成的核心建设，对应 Action。
- 每个节点只保留最能说明价值的规模、质量或业务指标，对应 Result。
- 面试时再选择英语三合一、单词测评或试卷学情分析中的一个案例，完整讲清需求、个人职责、技术方案和上线结果。

## 建议补充的实测指标（模拟口径）

以下是一组为了简历表达拟定的保守数据。正式使用时应保持前后口径一致，并能讲清对应样本、时间范围和计算公式；如果实际项目口径明显不符，应替换而不是继续叠加数字。

| 模块 | 模拟评测或日志口径 | 建议使用的结果 |
| --- | --- | --- |
| Context/Memory | 200 条超过 10 轮的长会话及跨会话追问 | 单次调用平均上下文 Token 降低 37%，关键信息召回率 71%→88% |
| 教材解析 | 891 本教材、约 18.2 万页 | 解析成功率 98.4%，产出约 32 万个 Chunk |
| RAG | 600 条按学科、年级分层抽样并人工标注的问题 | Recall@5 73%→86%，nDCG@5 0.69→0.80，Faithfulness 0.82→0.90，P95 1.8s→1.3s |
| 学习闭环 | 上线首月、约 8400 个入口展示会话 | 学习入口点击率提升 22%，任务完成率 71% |

- Context 对比口径：基线版本直接拼接完整历史，优化版本使用近期原文、历史摘要和长期记忆的动态预算装配。
- Memory 评测口径：为每条跨会话问题标注回答所需的用户偏好、学习状态或知识边界，按“成功召回的标注事实数/全部标注事实数”计算；若 200 条样本各含 1 个标注事实，71% 和 88% 分别对应召回 142 条和 176 条。
- RAG 对比口径：质量指标比较 Dense-only 与 Dense+BM25+RRF，延迟指标比较全库检索与元数据预过滤后的检索。
- 业务指标口径：点击率为点击学习 Action 的会话数/展示 Action 的会话数，完成率为完成学习任务数/进入任务数；结果回写只描述已打通的业务链路，不再单独编写成功率。

一页简历篇幅有限时，优先保留 **RAG Recall@5 73%→86%**、**教材页面解析成功率 98.4%**、**长会话 Token 降低 37%**、**学习任务完成率 71%** 四组结果，不再为 Agent Runtime 强行添加完成率或故障率。
